# Company identity on the application + a complete printable application

Approved scope: **A + B + C**, plus a rework of what the printed/downloaded application actually contains.

Company identity to be used everywhere:

```text
SUPERTRANSPORT, LLC
Pleasant Hill, Missouri
USDOT 2309365 · MC 788425
```

No street address anywhere (605 Madison St is dropped from these surfaces).

## What is being added

1. **A — Letterhead on the four standalone disclosure documents** (FCRA Authorization, PSP Authorization, DOT Drug & Alcohol Pre-Employment Questions, Certificate of Receipt — Company Testing Policy). Today each prints a plain text "SUPERTRANSPORT" wordmark and the line "Owner-Operator Fleet Services". That header is replaced with logo + legal name + Pleasant Hill, Missouri + USDOT/MC. The footer line on each doc gains the same identity, so page 2 of a filed copy is still attributable.

2. **B — Letterhead on the printed application.** The staff "Print application" output has no company identity at all today. It gains the same letterhead block plus a "Driver Application for Employment" title and the applicant name.

3. **C — Footer line on the online form** at `/apply`:
   `SUPERTRANSPORT, LLC · Pleasant Hill, Missouri · USDOT 2309365 · MC 788425`

## The bigger change: print the full wording

The printed application today is a **staff summary**, not the application. It prints short internal labels — "Safety history: Yes", "Testing policy: Yes", "In SAP process: No" — instead of the paragraph the applicant actually read and agreed to. On paper that is not defensible: it shows a checkbox state without the sentence it attached to.

The fix is to print the applicant-facing wording verbatim next to each answer, so the printed document reads as the application the driver completed.
