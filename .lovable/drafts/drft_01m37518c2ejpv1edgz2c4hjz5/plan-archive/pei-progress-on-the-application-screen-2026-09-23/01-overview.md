# PEI progress on the application screen

## First, your question: what "flag applicants with unsent checks" means

It is a banner at the top of the PEI Q. It lists every applicant whose record
says their previous-employer checks are in progress (or complete) while nothing
is actually out to any employer — exactly the state Marquis Bowie's file sat in
for seven weeks after a check was deleted. Each line names the applicant, the
status the record claims, the deadline if there is one, and an Open button.
Today William Westbrook would appear there.

It does not flag a check that is simply built and waiting for you to press send —
that is normal, and the new progress bar below is what shows it.

## The progress bar

On the application review screen, above the tabs, add a one-line PEI strip so
each employer's status is visible without opening the PEI Q:

- a segmented bar, one segment per employer, in employer order
- segment colours: grey = not sent, amber = out and waiting, green = completed
  or good-faith-effort documented
- text beside it: "Previous-employer checks 1/3 complete" plus, when any are
  unsent, "2 not sent yet"
- hovering a segment names the employer and its status; clicking the strip
  jumps to the PEI tab
- nothing shows when the applicant has no checks built yet, replaced by a quiet
  "No previous-employer checks built yet" line
- the PEI tab button also gets a small count badge (e.g. 1/3)

Driver-facing screens are untouched.
