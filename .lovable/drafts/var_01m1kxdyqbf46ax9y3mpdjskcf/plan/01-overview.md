# The email did not go to Tracey

The send record for Edward Williams, timestamped 14:41 UTC today, shows:

- **To:** marc@mysupertransport.com — only you
- **CC:** empty
- **Greeting:** Marc
- Logged as a **test send** (consultant not included), which is why the driver's "consultant notified" stamp was deliberately left alone

Tracey's address was removed before you clicked Send, and the send used exactly the list on screen. She received nothing.

## So what went wrong

The green line after sending is a fixed sentence. It always prints the name of the **saved** DOT Consultant on file — not the people the email actually went to. The same is true of the small toast that pops up. Both said "Tracey L. McQuilken" while the message itself was addressed to you.

It is a wording defect in the confirmation, not a delivery defect.
